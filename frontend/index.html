Project Overview

About the System

Deep Learning

The backend loads a ResNet34 PyTorch model once at startup and uses it to classify CT scans into Normal, Kidney Stone, Kidney Cyst, or Kidney Tumor.

Explainable AI

Every prediction includes a Grad-CAM visualization that highlights image regions most influential to the model output.

Technology Stack

FastAPI, PyTorch, Pillow, NumPy, HTML5, CSS3, and vanilla JavaScript.

Demo Friendly

No login or database is required. Each refresh starts a clean session, and results can be downloaded as a PDF report.
